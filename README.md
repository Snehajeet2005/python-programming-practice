# Python Programming Practice

A structured collection of beginner-to-intermediate Python programs and problem-solving exercises.

## About

This repository contains Python programs created to practice programming fundamentals, problem-solving, data structures, object-oriented programming, file handling, data processing, and introductory machine learning concepts.

The repository is organized topic-wise to make it easy to understand my progression from Python fundamentals to practical applications.

## Topics Covered

* Python basics
* Conditional statements and loops
* Functions and recursion
* Strings
* Lists and arrays
* Dictionaries and sets
* Problem-solving
* Object-oriented programming
* File handling
* Basic data processing
* Introduction to machine learning

## How to Run

Make sure Python 3 is installed.

Run any program from the terminal using:

```bash
python filename.py
```

For the machine learning and data-processing examples, install the required libraries:

```bash
pip install -r requirements.txt
```
